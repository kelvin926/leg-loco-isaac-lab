# Go2W–OpenArm Loco-Manipulation in Isaac Lab

This repository is based on NVIDIA Isaac Lab and contains my additions for Go2W–OpenArm wheeled-legged loco-manipulation experiments.

## What I added

- Unitree Go2W asset/configuration support
- Go2W–OpenArm task setup for KALO-style loco-manipulation experiments
- RSL-RL training and evaluation scripts
- Command-source extensions for scheduled and keyboard-based evaluation
- Evaluation utilities for early-launch experiments

## Research context

This code supports simulation-based experiments on constrained manipulator motion for early-launch behavior in a wheeled-legged platform.

## Environment

- Ubuntu 22.04
- NVIDIA GPU / CUDA-enabled environment
- Isaac Sim / Isaac Lab
- RSL-RL
- Python
